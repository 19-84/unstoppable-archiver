Understanding Rust Ownership

Published March 15, 2026 · 12 min read

Ownership is Rust's most unique feature, and it enables Rust to make memory safety guarantees without needing a garbage collector.

What is Ownership?

All programs have to manage the way they use a computer's memory while running. Rust uses a system of ownership with rules that the compiler checks at compile time.

fn main() {
    let s1 = String::from("hello");
    let s2 = s1;
    // s1 is no longer valid
    println!("{}", s2);
}
  • Each value has an owner.
  • One owner at a time.
  • Owner out of scope → value dropped.
